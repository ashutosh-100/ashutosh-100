# 💫 About Me:
I’m Ashutosh Dhingya, a motivated Computer Science student with a strong passion for cybersecurity. My focus is on applying certified skills in cyber hygiene, Microsoft security frameworks, and network defense to help protect digital assets and infrastructure. I’m deeply interested in understanding both defensive and offensive security tactics, which I explore through hands-on projects like building a Password Hash Cracker to uncover cryptographic vulnerabilities. I’m eager to begin my career in information security and contribute to building safer digital environments. When I’m not studying cybersecurity, I enjoy exploring how everyday technology can be secured—sometimes even testing my own tools to see how quickly common passwords can be cracked (always ethically, of course!).
